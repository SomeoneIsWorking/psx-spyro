# Codemap — Spyro 1, 2 and 3

Dependency direction: `titles/<title>/` (one image's facts and natives) → `game/` (what S1, S2 and S3 share) → `external/psxport` (everything every PSX title shares); `game/` never names a title, and `game/` and `titles/` are the include roots (`"core/runtime.h"`, `"spyro1/render/sky.h"`).

Frame loop: not owned. Spyro 1 runs update `0x8003385C` and draw `0x8001ED5C` and delivers fields as the guest clock crosses them (`FieldOwner`); Spyro 2/3 run update/draw (`0x8001B140`/`0x800156FC`, `0x80055400`/`0x8001E638`) and answer each guest VSync with one field (issue 0217).

- `game/core/title_runtime_registry.*` — product catalog / title picker entries: the three runtimes and their generated identities
- `game/core/runtime.*` — Spyro runtime base: session, state producers, presentation pacing, widescreen projection policy, panel logo, run report
- `game/core/session.*` — per-Core title state: archive transfer, disc landing count, field owner, HUD draw context, state producers
- `game/core/field_owner.*` — display field / VSync delivery sequence: pad, clock, VBlank root counter, observers, snapshot, presentation fence, audio, host turn
- `game/core/boot_prefix_runtime.*`, `boot_prefix_frame_driver.*` — S2/S3 boot: crt0, stock libraries, the retail boot prefix as a resumable call, then update and draw one field per step, the replay sampled before each draw, each logic frame presented when its draw returns, each field of the fade-before-load loop presented on its own
- `game/core/draw_section.*` — S2/S3 per-field draw body as a replay section: buffer flip, camera builder and position copy, the image's state switch (subclasses in `titles/spyro2|3/core/draw_section.*`), flatten; the device tail skipped
- `game/core/draw_motion.*` — what the S2/S3 replay moves: camera, Spyro, his poses, surface (tint, water, reflection, rotation: `SpyroSurface`) and shadow, the flame breath (`FlameMotion`), every moby slot (`MobyMotion`), the effects pools (`EffectMotion`, a `MotionSource`), the fades, S2's conversation box slide (`ConversationSlide`)
- `game/core/hud_slide.*` — S2's HUD counter slide `0x80052498` as a native override and `MotionSource`: each call's offset blended inside a replay (`HudSlide`)
- `game/core/sky_wave.*` — S2's sky-object wave as a `MotionSource`: the consumer `0x800296D0` overridden to write the wave word `t` of the way between ticks inside a replay (`SkyWave`)
- `game/core/table_slide.*` — a slide the draw reads from one table entry per tick, as a `MotionSource` (S1 title logo, S2 conversation box)
- `game/core/frame_cut.*` — cut detection for 60 fps in-betweens: gamestate, level, camera placement, a cutscene camera track's shot change
- `game/core/native_execution.h` — nested guest call return address `$ra` and lowered stack frame
- `game/core/archive_transfer*` — WAD archive / CD file transfer with per-Core completion and refusal
- `game/core/guest_magnitude.*` — reciprocal magnitude / vector length normalise step, GTE square sum and square root table
- `game/core/title_logo*` — title wordmark for the picker panel, rebuilt from the title screen's draws at its gate
- `game/core/debug/debug_menu.*` — `spyro::DebugMenu`, the title debug menu (psxport `TitleDebugMenu`): the warp catalogue (homeworld, level, arrival) named from each title's guest name tables and grouped under the homeworld its guest table gives each level, moby listing and teleport verbs; S1/S2 derive their own
- `game/core/debug/warp.*` — the warp arrival: the level entered from the idle title screen or, where the title has a route, from gameplay, change after change from wherever the game resumes play until gameplay is in it, then an optional placement
- `game/core/debug/moby_teleport.*` — `mobys <class>` / `moby-teleport <class> <n>`: list a level's mobys of one class and place Spyro on one (NPC conversation, dragon rescue routes); each title names its moby array, active field and position words
- `game/render/engine_render_overrides.*` — S2/S3 render overrides bound to one image: terrain drawer, moby walk, sky drawer, flatten depth bins, fullscreen tint and letterbox
- `game/render/screen_overlays.*` — fullscreen tint / fade and cinematic letterbox producers shared by all three images; in an S2/S3 replay the letterbox's moving edge is placed between the row read and the row drawn
- `game/render/field/effect_pools.*` — S2/S3 effects pass pools (sprites, glows, beams, trails, vertex meshes, particles): one field's records read, paired by slot and moved for the replay
- `game/render/field/keyframe_blend.*` — moby / Spyro animation keyframe pair and progress (S2/S3 nibbles, S1 64ths and 16ths), pose between two fields and across an animation switch
- `game/render/field/moby_motion.*` — a moby slot between two samples for all three replays: the moby array's records, position, angles, pose across an animation switch; titles subclass for layout test and own words
- `game/render/field/moby_record.*`, `record_blend.h` — moby record layout and identity, record lerp, little-endian field load/store and angle lerp shared by S1 and S2
- `game/render/field/guest_moby_*` — moby / object visibility walk: sphere frustum cull, GTE use, orientation onto camera rotation; whether a record's two animation slots share a vertex layout
- `game/render/field/moby_pose.*` — S2/S3 model-space vertices of one moby render-list entry: the drawer's vertex streams decoded and blended toward frame B
- `game/render/field/intro_card.*` — S2/S3 title intro card at 16:9: the moby drawer, then the card's front-face rows continued into the margins in its own model space
- `game/render/field/guest_sky_drawer.*` — S2/S3 sky drawer: visible sky sectors projected and outcoded against the presented window, triangle strips chained one bin past the mark
- `game/render/field/spyro_drawer_depth.*` — S2/S3 player drawer's native depth: his view unit and bias byte per call, slot order for the reflection and unbinned passes
- `game/render/field/guest_view_slope.*` — horizontal frustum slope, screen margin and outcode window at 4:3 or widened 16:9
- `game/render/field/guest_render_globals.h` — camera, ordering-table, overlay-pair and packet-cursor guest words per image
- `game/render/field/guest_working_memory.h` — packet tag link, rotation words
- `game/render/field/guest_word.h` — MIPS word arithmetic: signed view, `sra`, absolute value, sign-extended halfword, packed 11/11/10 delta fields
- `game/render/field/guest_packet.h` — GP0 packet tags, packet sizes and command words the emitters write
- `game/render/state_producer_override.h` — native draw override installed with the state producer that renders its saved draw
- `game/render/hud/ui_anchor.*` — HUD / screen-space UI horizontal anchoring on a widened canvas
- `game/render/terrain/guest_terrain_drawer.*`, `guest_terrain_facts.h`, `guest_terrain_frame.h`, `guest_terrain_passes.h` — terrain / world / level geometry drawer: entry and exit, one image's facts, per-call state, pass order, field windows
- `game/render/terrain/engine_terrain_image.*` — S2/S3 terrain drawer as one TerrainImage
- `game/render/terrain/guest_terrain_*` (classify, sphere, animation, mesh, cull, screen, far, far_vertices, detail, translucent, polygon, coarse, fine, split, grid, resplit, fog) — terrain passes: sector classification and bounding sphere, sector animation, vertex projection (RTPS), outcode and NCLIP culls, far LOD and its far bin limit / deepest ordering-table mark, near detail and translucent, subdivision grids, split pieces and edge cracks, re-split of oversized polygons, distance fog
- `game/render/terrain/guest_camera_builder.*` — guest camera builders (S2/S3 0x8001C2F8, S1 0x80033C50) over the guest's angle tables
- `game/render/terrain/guest_depth_bins.*` — depth bins and overlay pair / ordering-table slot of each packet before the flatten (the overlay slot constant)
- `titles/spyro1/core/runtime/` — S1 runtime: crt0, stock bindings, native leaves, pad delivery, Record capabilities, cut, title command
- `titles/spyro1/core/guest_globals.h`, `guest_gp.h`, `guest_functions.h` — S1 guest globals, gp, callee entries, names from the spyro-1 decomp
- `titles/spyro1/core/native_state.h` — S1 title state: shaded-line call sites, replay angle fractions
- `titles/spyro1/core/execution/` — S1 native leaves: vector math, GTE geometry, angles, rand and random range, utilities, level initialisation, cooperative CD loader queue
- `titles/spyro1/core/frame/` — S1 main loop: frame driver, GamestateDraw and its VSync tail, boot sequence and logos, Start press latch, transition skip, skip map, draw setup, update budget, logo facts; `draw_section.*` the GS_Playing and title-screen draws as a replay section (the camera matrices rebuilt from the fine angles), `title_slide.*` the title logo and border slides (a `TableSlide`), `title_fade.*` the title's fade level between ticks (a `MotionSource` the title draw reads), `texture_scroll.*` water and lava scroll's motion source, `draw_motion.*` its motion tracks and record rules (camera, Spyro, mobys, HUD, particles, sparkles, flame, counters), `draw_cuts.*` the camera snap, preset reset and Spyro reset that declare a cut
- `titles/spyro1/core/audio/` — S1 sound: libspu natives, SPU registers, voices, pitch, key status, positional moby sound
- `titles/spyro1/core/moby/` — S1 mobys / game objects: allocator, lists, transform, animation, collision, collision shade, environment light, `scroll_bake.h` texture scroll bake (0x8002A6FC), shaded queue, shared models (PETE.WAD), level globals table
- `titles/spyro1/core/player/` — S1 player: Spyro physics, body / head / tail animation, cutscene playback
- `titles/spyro1/core/camera/` — S1 camera state
- `titles/spyro1/core/effect/` — S1 effects: ground shadow block and ring, flame block, particle pool allocation
- `titles/spyro1/core/hud/` — S1 HUD: collectables, pause menu, pixel fade
- `titles/spyro1/core/input/` — S1 gamepad buffers, input phase for `.pad` recordings
- `titles/spyro1/core/debug/` — S1 debug menu (`spyro1::DebugMenu`), S1 warp route (reset then TSD_Level flyby from the title, `CheatProcessLevelWarp` from play); the portal and dragon arrivals of each level (`teleport`: Spyro in front of the level's hub portal, onto a crystal dragon for the rescue cutscene), `gates` / `dragons` listings; `where` / `spyro-at` read and set Spyro's position; `mobys` / `moby-teleport` onto any moby by class (on `game/core/debug/moby_teleport`)
- `titles/spyro1/render/terrain_*` — S1 terrain drawer RenderWorldChunks: sector loop, far, detail, coarse and fine subdivision passes, facts
- `titles/spyro1/render/actor_*`, `lit_actor_emitter.*`, `local_bins.*` — S1 actors / mobys: draw list builders, emitters (flat light, reflection), emitter passes, layouts, local depth bins; `replay_angles.h` the sub-step angle fractions a replay notes per moby for the list builders
- `titles/spyro1/render/sprite_queue*` — S1 sprite queue: lit and HUD mobys
