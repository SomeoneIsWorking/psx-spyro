# Codemap — Spyro 1, 2 and 3

Dependency direction: `titles/<title>/` (one image's facts and natives) → `game/` (what S1, S2 and S3 share) → `external/psxport` (everything every PSX title shares); `game/` never names a title, and `game/` and `titles/` are the include roots (`"core/runtime.h"`, `"spyro1/render/sky.h"`).

- `game/core/title_runtime_registry.*` — product catalog / title picker entries: the three runtimes and their generated identities
- `game/core/runtime.*` — Spyro runtime base: session, state producers, presentation pacing, widescreen projection policy, panel logo, run report
- `game/core/session.*` — per-Core title state: archive transfer, field owner, HUD draw context, terrain visibility, state producers
- `game/core/field_owner.*` — display field / VSync delivery sequence: pad, clock, VBlank root counter, observers, snapshot, presentation fence, audio, host turn
- `game/core/boot_prefix_runtime.*`, `boot_prefix_frame_driver.*` — S2/S3 boot: crt0, stock libraries, the retail boot prefix as a resumable call, then update and draw one field per step, each logic frame presented when its draw returns, each field of the fade-before-load loop presented on its own
- `game/core/frame_cut.*` — cut detection for 60 fps in-betweens: gamestate, level, camera placement, a cutscene camera track's shot change
- `game/core/native_execution.h` — nested guest call return address `$ra` and lowered stack frame
- `game/core/archive_transfer*` — WAD archive / CD file transfer with per-Core completion and refusal
- `game/core/guest_magnitude.*` — reciprocal magnitude / vector length normalise step, GTE square sum and square root table
- `game/core/title_logo*` — title wordmark / logo snapshotted from guest VRAM for the picker panel
- `game/core/debug/debug_menu.*` — `spyro::DebugMenu`, the title debug menu (psxport `TitleDebugMenu`): level warp verb over each title's level ids, moby teleport verbs; S1/S2 derive their own
- `game/core/debug/warp.*` — `warp <level>` request / level select / dev warp, applied when the title screen is idle
- `game/core/debug/moby_teleport.*` — `mobys <class>` / `moby-teleport <class> <n>`: list a level's mobys of one class and place Spyro on one (NPC conversation, dragon rescue routes); each title names its moby array, active field and position words
- `game/render/engine_render_overrides.*` — S2/S3 render overrides bound to one image: terrain producer, moby walk, field dispatcher and its last drawer, flatten depth bins and field producer
- `game/render/field/field_redraw.*` — S2/S3 field in-between: the draw dispatcher re-run as a guest redraw at the in-between camera, mobys, Spyro and effects, its packets saved by the flatten as the field's state, the sky moved at the flatten to the deeper of the two real fields' sky bins; the Spyro 3 pause menu's second moby pass (Sparx) redrawn in its own depth table; packets a producer keyed passed over in the bins before the redraw runs; screen draws (a state's draw with 2D after the dispatcher, title overlays keyed by the landed read's published content, the replaced image's override removed) redrawn whole
- `game/render/screen_overlays.*` — fullscreen tint / fade and cinematic letterbox producers shared by all three images
- `game/render/field/loading_picture.*` — S2/S3 loading screen picture: page sprites faded in by a counter, saved with their packets, redrawn at the in-between brightness
- `game/render/field/effect_pools.*` — S2/S3 effects pass pools (sprites, glows, beams, trails, vertex meshes, particles): one field's records read, paired by slot and moved for the in-between
- `game/render/field/keyframe_blend.*` — moby / Spyro animation keyframe pair and progress (S2/S3 nibbles, S1 64ths and 16ths), pose between two fields and across an animation switch
- `game/render/field/moby_record.*`, `record_blend.h` — moby record layout and identity, record lerp, little-endian field load/store and angle lerp shared by S1 and S2
- `game/render/field/guest_moby_*` — moby / object visibility walk: sphere frustum cull, GTE use, orientation onto camera rotation
- `game/render/field/guest_view_slope.*` — horizontal frustum slope, screen margin and outcode window at 4:3 or widened 16:9
- `game/render/field/guest_render_globals.h` — camera, ordering-table, overlay-pair and packet-cursor guest words per image
- `game/render/field/guest_working_memory.h` — in-between packet arena window, packet tag link, rotation words, saved draws
- `game/render/field/guest_word.h` — MIPS word arithmetic: signed view, `sra`, absolute value, sign-extended halfword
- `game/render/field/guest_packet.h` — GP0 packet tags, packet sizes and command words the emitters write
- `game/render/state_producer_override.h` — native draw override installed with the state producer that renders its saved draw
- `game/render/hud/ui_anchor.*` — HUD / screen-space UI horizontal anchoring on a widened canvas
- `game/render/terrain/guest_terrain_drawer.*`, `guest_terrain_facts.h`, `guest_terrain_frame.h`, `guest_terrain_passes.h` — terrain / world / level geometry drawer: entry and exit, one image's facts, per-call state, pass order, field windows
- `game/render/terrain/engine_terrain_image.*` — S2/S3 terrain drawer as one TerrainImage
- `game/render/terrain/guest_terrain_*` (classify, sphere, animation, mesh, cull, screen, far, far_vertices, detail, translucent, polygon, coarse, fine, split, grid, resplit, fog) — terrain passes: sector classification and bounding sphere, sector animation, vertex projection (RTPS), outcode and NCLIP culls, far LOD and its far bin limit / deepest ordering-table mark, near detail and translucent, subdivision grids, split pieces and edge cracks, re-split of oversized polygons, distance fog
- `game/render/terrain/guest_camera_builder.*` — guest camera builder re-run for an in-between camera
- `game/render/terrain/guest_depth_bins.*` — depth bins and overlay pair / ordering-table slot of each packet before the flatten (the overlay slot constant), the field's claim of unkeyed packets
- `game/render/terrain/terrain_rebuild.*`, `terrain_state_producer.*` — terrain interpolation: drawer re-run over saved words at an in-between camera, terrain state producer
- `titles/spyro1/core/runtime/` — S1 runtime: crt0, stock bindings, native leaves, pad delivery, Record capabilities, cut, title command
- `titles/spyro1/core/guest_globals.h`, `guest_gp.h`, `guest_functions.h` — S1 guest globals, gp, callee entries, names from the spyro-1 decomp
- `titles/spyro1/core/execution/` — S1 native leaves: vector math, GTE geometry, angles, rand and random range, utilities, level initialisation, cooperative CD loader queue
- `titles/spyro1/core/frame/` — S1 main loop: frame driver, GamestateDraw and its VSync tail, boot sequence and logos, Start press latch, transition skip, skip map, draw setup, update budget, logo facts
- `titles/spyro1/core/audio/` — S1 sound: libspu natives, SPU registers, voices, pitch, key status, positional moby sound
- `titles/spyro1/core/moby/` — S1 mobys / game objects: allocator, lists, transform, animation, collision, collision shade, environment light, shaded queue, shared models (PETE.WAD), level globals table
- `titles/spyro1/core/player/` — S1 player: Spyro physics, body / head / tail animation, cutscene playback
- `titles/spyro1/core/camera/` — S1 camera state
- `titles/spyro1/core/effect/` — S1 effects: ground shadow block and ring, flame block, particle pool allocation
- `titles/spyro1/core/hud/` — S1 HUD: collectables, pause menu, pixel fade
- `titles/spyro1/core/input/` — S1 gamepad buffers, input phase for `.pad` recordings
- `titles/spyro1/core/debug/` — S1 debug menu (`spyro1::DebugMenu`), S1 warp route (reset then TSD_Level flyby); `teleport`: `gates` / `gate-teleport` onto a level portal, `dragons` / `dragon-teleport` onto a crystal dragon (the rescue cutscene route); `mobys` / `moby-teleport` onto any moby by class (on `game/core/debug/moby_teleport`)
- `titles/spyro1/render/terrain_*` — S1 terrain drawer RenderWorldChunks: sector loop, far, detail, coarse and fine subdivision passes, facts
- `titles/spyro1/render/actor_*`, `lit_actor_emitter.*`, `local_bins.*` — S1 actors / mobys: draw list builders, emitters (flat light, reflection), layouts, producers, in-between record blend and host-memory run (`InBetween`), local depth bins
- `titles/spyro1/render/sprite_queue*` — S1 sprite queue: lit and HUD mobys, producer
- `titles/spyro1/render/paired_actor*` — S1 Spyro model draw (RasterizePairedActor), producer
- `titles/spyro1/render/sky*` — S1 sky / cyclorama and the walk a portal's own sky shares with it, producer
- `titles/spyro1/render/portal*` — S1 portal drawer: outline, far fill, near sky cut to the outline, sky spin, producer
- `titles/spyro1/render/moby_shadow*` — S1 moby shadows (RenderMobyShadows), producer
- `titles/spyro1/render/drop_shadow*` — S1 Spyro drop shadow, producer
- `titles/spyro1/render/flame*` — S1 flame breath (DrawSpyroHornStrikeTrails): tip fans and arc ribbons, producer
- `titles/spyro1/render/rescue_star*` — S1 dragon-rescue star burst over a freed dragon, producer
- `titles/spyro1/render/glow*` — S1 glow fans and sparkles, their emitter and sparkle pools, producers
- `titles/spyro1/render/ordering_table.*` — S1 LinkOTPrimitives / ordering table slots
- `titles/spyro1/render/hud_anchor.*` — S1 HUD anchor class per HUD record
- `titles/spyro1/render/screen_overlays.h` — S1 facts for the shared tint and letterbox
- `titles/spyro1/render/title_sprites.*` — S1 title screen sprites (logo slide, PRESS START, memory card menus) producer, installed per title overlay landing
- `titles/spyro1/render/particle*` — S1 particles / emit list, producer
- `titles/spyro1/render/screen.h` — S1 retail outcode window for widened culls
- `titles/spyro1/render/pause_backdrop.*` — S1 pause backdrop: the grey read-back page (func_80017E98) declared as a read-back texture
- `titles/spyro1/render/shaded_line.*` — S1 shaded border line (func_8001844C): pause, flight and balloonist borders, producer keyed by endpoints
- `titles/spyro2/core/`, `titles/spyro3/core/` — S2/S3 runtime: crt0, stock libraries, interrupt-driven libcd, module landing, packet pool, cut, logo; boot facts (boot prefix, update / draw, gamestate and level words); warp route through the title screen's Start teardown; S2 debug menu (`spyro2::DebugMenu`) with `mobys` / `moby-teleport`
- `titles/spyro2/render/`, `titles/spyro3/render/` — S2/S3 render facts per image, HUD widget anchoring; S2 conversation producers: box and name tab (slide lerp), underline and text (held to the earlier field)
- `titles/*/executable.json`, `titles/*/README.md` — title manifest: serial, hashes, labels, disc keys
- `CMakeLists.txt`, `pyproject.toml`, `uv.lock`, `.github/` — `spyro_port` product, title catalog generation, locked Python environment, release CI
- `run.sh`, `bootstrap.py`, `tools/run.py`, `tools/provision_title.py`, `tools/generate_title_catalog.py`, `tools/title_identity.py`, `tools/shipping_settings.ini` — player launcher, framework fetch, provisioning, catalog generation, identity check, shipped settings
- `tools/guest_globals.py`, `tools/re_globals.py`, `tools/title_profile.py`, `tools/title_states.py`, `tools/title_prompts.py` — guest addresses read from the C++ headers, globals a function touches, per-title words, gamestate tables, title-screen prompts
- `tools/drive.py`, `tools/press_conditions.py`, `tools/spyro1_steering.py`, `tools/repl_*.py`, `tools/route_scenes.py`, `tools/routes/`, `tools/live_play.py`, `tools/title_route.py`, `tools/title_conversation.py`, `tools/boot_run.py`, `tools/boot_log.py`, `tools/determinism_check.py`, `tools/shot.py`, `tools/pad_replay.py`, `replays/` — agent drivers: REPL routes, steering, boot runs, determinism, captures, `.pad` replays
- `tools/oracle_*.py` — Spyro 1 oracle comparison checkpoints and attract-demo route
